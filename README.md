# Olamide Akinola — Portfolio Website

A personal portfolio website built to showcase my projects, technical skills, education, and professional background as a Frontend Developer.

The website is built with HTML, CSS, and vanilla JavaScript, with a focus on responsive design, interactive user experiences, and a clean, accessible presentation.

**Live Website:** ["View Portfolio"](https://omoakin1-devburn.github.io/portfolio-website/)

## Overview

This portfolio serves as a central place to explore my development projects, technical skills, background, and contact information.

It reflects my current development experience and provides an overview of the projects I have built while continuing to strengthen my frontend development skills.

## Features

- **About Me** — Introduction to my background, education, development interests, and technical focus.
- **Skills** — Overview of my current technical skills and technologies.
- **Projects** — Selected projects with descriptions and direct links to their GitHub repositories.
- **Contact Section** — Contact options through email and WhatsApp, including a quick-message contact form.
- **Social Links** — Direct links to my GitHub and LinkedIn profiles.
- **Light/Dark Theme Toggle** — Allows visitors to switch between light and dark themes.
- **Responsive Design** — Adapts to desktop, tablet, and mobile screen sizes.

## Technologies & Tools

- **HTML5** — Semantic page structure and content.
- **CSS3** — Styling, layout, animations, and responsive design.
- **JavaScript (Vanilla)** — Interactivity, dynamic behavior, and functionality.
- **Font Awesome** — Icons used throughout the interface.
